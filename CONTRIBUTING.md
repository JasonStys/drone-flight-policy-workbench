# Contributing

Jason Stys: small reviewed changes with independent evidence, source traceability and honest limits.

Use original synthetic inputs only. Run every README gate, update docs and regenerate/check exact source/file navigation. Keep dependency hashes, OPA checksums and immutable workflow references. No artifact/cache uploads, advisory suppressions, lowered coverage thresholds, retry-to-green or mocked-provider success.

Policy changes require native cases and independent oracle checks, explicit date/context/units/quality semantics, and no flight-permission claims. Access changes require role/object/CSRF tests; persistence changes require transaction/race/rollback/immutability evidence. UI changes need actual-service desktop/mobile acceptance, accessibility and stale-draft regressions.

Do not add real approval documents, aircraft commands, identity lookup, persistent person tracking, external data collection or remote exposure under the guise of a small refactor. Those would require separate authorized requirements and a new threat model.
